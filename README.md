# Urban-Livability-Index

A data-driven project to evaluate and rank residential areas in Pune based on multiple real-world factors such as price, traffic congestion, air quality, and growth potential.

---

##  Project Overview

This project develops an **Urban Livability Index** that combines multiple parameters into a single score to help users identify the best areas to live in Pune.

---

##  Features

- Ranking of areas based on livability score  
- Identification of the best area to live  
- Interactive filtering (price, AQI, congestion)  
- Personalized recommendation system using user preferences  
- Data visualization using Power BI (KPI, slicers, bar charts)
  
---

##  Methodology

- Data collection & cleaning (Python, Pandas)  
- Min-Max normalization  
- Weighted scoring model:
    Score = 0.30 Price + 0.25 Congestion + 0.25 AQI + 0.20 Growth
- PostgreSQL for storage  
- Power BI for visualization
  
---
